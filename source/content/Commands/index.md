Comprobot's Discord commands are split into four categories.

| Category | Commands |
| --- | --- |
| General | ASCII Art, Bible, Bitcoin, Calculate, Cat, Chuck Norris, Currency, Dare, Dog, Duck, Fact, Help, Joke, Meme, Never Have I Ever, Paranoia, QR Code, Quote, Reminder, Trivia, Truth, Waifu, WYR |
| Money | Add Money, Remove Money, Balance |
| Settings | Profile Picture, Banner, Change Name, Change Keywords |
| Moderation | Purge |

All commands use the prefix configured in `config.toml` (default `!`). Settings commands are subcommands of the settings group, e.g. `!config pfp`.
