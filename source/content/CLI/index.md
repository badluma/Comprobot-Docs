Comprobot is controlled from the command line using the `comprobot` command. Running it without any arguments prints the help message, and `comprobot -v` prints the current version.

| Command | Description |
| --- | --- |
| [start](Start) | Start the bot |
| [dashboard](Dashboard) | Start the web dashboard |
| [onboard](Onboard) | First-time setup wizard |
| [config](Config) | Edit configuration files |
| [test](Test) | Test a command without a live bot |
| [reset](Reset) | Reset configuration files to their defaults |
